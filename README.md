Tic-Tac-Toe with Simple AI

📌 Project Overview

This project is a Tic-Tac-Toe game developed using Python and Tkinter. It allows a user to play against a simple AI opponent in an interactive graphical interface.

✨ Features

- Interactive GUI using Tkinter
- Player vs Computer gameplay
- Simple AI opponent
- Automatic win, loss, and draw detection
- Restart Game option

🛠 Technologies Used

- Python 3
- Tkinter

▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run the following command:

python tictactoe_gui.py

📂 Project Files

- "tictactoe_gui.py" – Main game source code
- "README.md" – Project documentation
